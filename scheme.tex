\section{研究方案}

\subsection{研究内容}
\begin{enumerate}[label=\arabic*., leftmargin=2em]
    \item \textbf{三维框架（杆、梁）结构有限元离散方案：}针对冷弯薄壁型钢框架结构中杆、梁构件的几何与受力特点，研究适用的低阶/高阶单元列式及减缩积分、假设应变等免自锁策略，建立静力、动力及稳定分析统一框架，并发展等效外荷载计算与节点校核方案。
    \item \textbf{梁杆结构静动力分析测试与验证：}设计覆盖轴向、弯曲、剪切及组合受力状态的算例，结合理论解、商业有限元软件（ABAQUS/ANSYS）结果以及课题组自主程序 ApproxOperator.jl 的计算结果，对模块的精度、收敛性与计算效率进行系统验证。
    \item \textbf{多国规范校核方案制定：}针对中国 GB 50018《冷弯薄壁型钢结构技术规范》、北美 AISI S100、欧洲 EC3 等主流规范，建立截面强度、构件稳定、整体稳定及连接验算的接口与流程，实现分析结果向规范校核的自动化映射。
    \item \textbf{工程案例应用与反馈优化：}依托大禾众邦提供的典型轻钢建筑项目，开展模块的工程应用测试，根据用户反馈持续优化计算流程、结果可视化与交互体验。
\end{enumerate}

\subsection{三维框架（杆、梁）结构有限元离散的研究方案}
\begin{enumerate}[label=\arabic*., leftmargin=2em]
    \item \textbf{运动学假设与广义应变：}基于梁理论确立位移场的运动学假设，建立节点自由度与几何变形的映射关系，推导出包含轴向、弯曲及剪切效应的广义应变分量，为有限元列式提供小变形下的应变基础。
    \item \textbf{Galerkin弱形式与本构关系：}基于虚功原理建立积分弱形式，确立广义内力变量与广义应变之间的力学本构关系。通过关联刚度参数与变形效应，为后续刚度矩阵的推演和广义内力的提取构建理论依据。
    \item \textbf{有限元离散与形函数：}针对三维框架结构中的杆、梁单元，采用两节点空间线单元模型，并按空间框架的节点自由度（如轴向、横向及转动等）进行单元自由度布置。利用线性形函数将连续域的场变量插值离散为节点自由度，实现连续系统向有限自由度系统的转化。
    \item \textbf{自锁问题的通用处理：}针对低阶梁/杆单元易于出现的剪切自锁缺陷，采用通用化的数值策略（如混合离散或缩减积分）进行处理。该方法旨在修正低阶单元离散化过程中的自锁问题，确保在不同几何参数条件下均能保持物理上正确的力学响应。
    \item \textbf{刚度矩阵的统一组装：}基于上述框架，将多种力学效应对应的分块刚度矩阵进行叠加，最终组装成消除剪切自锁的完整单元刚度矩阵，并建立有限元线性方程组的基本形式 \(\mathbf{K}\mathbf{d} = \mathbf{f}\)。该方案兼顾了通用性与计算效率，为后续的静动力分析奠定离散化基础。
\end{enumerate}

\subsection{梁杆结构静动力分析测试与验证的研究方案}
\begin{enumerate}[label=\arabic*., leftmargin=2em]
    \item \textbf{边界约束处理与方程降维：}依据标准有限元约束处理方法，对全局有限元平衡方程 \(\mathbf{K}\mathbf{d} = \mathbf{f}\) 进行自由度凝聚与消去操作，将全自由度刚度矩阵方程降维简化为仅由未知自由度组成的小规模可解线性方程组。
    \item \textbf{刚度与变形模式精度验证：}通过直接求解上述降维后的线性方程组 \(\mathbf{K}\mathbf{d} = \mathbf{f}\)，获得特定受力工况下的节点自由度的解\(\mathbf{d}\)。
    \item \textbf{内力变量反算与平衡一致性检验：}将求解得到的节点位移解回代入应变-位移关系和本构方程，反算截面处的广义内力变量。
    \item \textbf{多工况数值对比与参数化收敛性分析：}设计涵盖轴心受力、弯曲及组合受力等多种典型载荷类型与边界条件的算例集。系统改变刚度与几何参数进行测试，并与商业有限元软件的细观模型结果进行交叉对比，全面评估模块的计算精度与收敛效率。
    \item \textbf{工程规范公式的映射测试：}将反算得到的广义内力变量组合，直接代入规范对应的强度与稳定校核公式中进行解析验算。
\end{enumerate}

\subsection{多国规范校核方案制定的研究方案}
\begin{enumerate}[label=\arabic*., leftmargin=2em]
    \item\textbf{规范条文的逻辑梳理与参数化表达：}系统梳理不同国家及地区钢结构规范（如中国GB50018、北美AISI S100、欧洲EC3等）中关于构件强度、整体稳定、局部稳定及连接计算的具体要求，将其校核流程与逻辑转化为程序可执行的参数化判定依据。
    \item\textbf{有限元分析结果与规范输入的映射接口：}建立有限元广义内力变量（如轴力、弯矩、剪力等）与多国规范验算所需参数之间的自动化映射关系。设计统一的数据接口标准，确保分析模块输出的数据能够传递给后续的规范验算器，解决数据孤岛问题。
    \item\textbf{核心计算方法与设计理论的程序化封装：}针对各规范中特定的承载力计算理论与验算公式（如有效截面属性计算、直接强度法等），采用可扩展的架构设计，将不同规范下差异化的计算逻辑进行分类封装，使得系统能够根据用户指定的规范类型调用对应的验算模块。
\end{enumerate}

\subsection{工程案例应用与反馈优化的研究方案}
依托合作企业提供的典型轻钢建筑项目，构建面向实际工程工况的算例数据集，并将模块部署至真实工程场景中开展全流程解算测试。在测试过程中深入设计一线，收集工程人员在数据交互与结果后处理等环节的反馈意见。最终依据实测数据与用户建议，通过“应用-反馈-优化”的模式，对模块的计算性能、可视化效果进行持续改进，确保模块能够稳定高效地服务于一线工程生产。

\subsection{技术路线}
本项目的技术路线如图~\ref{fig:tech-route} 所示。首先，通过文献调研与企业需求访谈，明确冷弯薄壁型钢框架结构有限元分析的功能需求与性能指标；其次，基于课题组自主程序 ApproxOperator.jl，发展免自锁的杆/梁单元列式，构建静力、动力与稳定分析的统一计算框架；再次，设计覆盖典型受力状态的测试算例，与理论解及 ABAQUS/ANSYS 结果进行对比验证；随后，针对 GB 50018、AISI S100、EC3 等规范建立校核接口；最后，将模块集成至 BuildingMaster（BM）设计软件，并依托大禾众邦工程案例开展应用测试与迭代优化。

\subsection{研究方法}
本项目采用文献调研、理论推导、数值实验、对比验证与工程应用相结合的研究方法：

\begin{itemize}[leftmargin=2em]
    \item \textbf{文献调研法：}系统梳理冷弯薄壁型钢结构有限元分析、免自锁单元、稳定分析及相关规范校核方面的国内外研究进展，明确技术路线与关键科学问题。
    \item \textbf{理论推导法：}基于变分原理与有限元方法，推导适用于薄壁杆/梁结构的单元刚度矩阵、质量矩阵及几何/材料非线性列式，建立免自锁分析方案。
    \item \textbf{数值实验法：}在 ApproxOperator.jl 平台上实现算法原型，通过标准算例测试单元的收敛性、精度与计算效率。
    \item \textbf{对比验证法：}将本项目计算结果与理论解、ABAQUS/ANSYS 商业软件结果及试验数据进行对比，验证模块的可靠性。
    \item \textbf{工程应用法：}依托大禾众邦提供的真实工程案例，开展模块应用测试，收集用户反馈并持续优化。
\end{itemize}

评价指标主要包括：位移/应力计算精度、屈曲临界荷载误差、计算收敛阶、单工况计算耗时、与商业软件结果的一致性以及规范校核覆盖率。
